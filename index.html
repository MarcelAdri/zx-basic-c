Invoerhulp (Toetsenbord)

De Spectrum gebruikt speciale invoermodi:
Keyword (eerste aanslag, later met CTRL + K : [K] (Commando's, bijv. P = PRINT)
Lettterlijke invoer : [L] (Letters en cijfers, midden in een zin)
CTRL + F : [F] (Groene functies boven de toest, bijv. Q = SIN)
CTRL + L : [E] (Rode symbolen op de toets, bijv. W = <>)
CTRL + G : [E] (Rode symbolen onder de toets, bijv. W = ACS)
Typ om te testen. Druk op Enter om de bytes naar C te sturen!
